## English copy

**Free Next.js lead table starter for CRM and internal dashboard projects**

I built a small Next.js + TypeScript lead table with name/company search, status filtering, combined filters and an empty state. On narrow screens, the table scrolls inside its container.

It uses 12 fictional contacts and runs without an account or API key. The sample source is MIT-licensed and includes a setup guide, lockfile and tests.

Try it: https://leadflow-table-sample.daotungduong-photos2.chatgpt.site

Source: https://github.com/daoduong007/leadflow-table-sample

The free sample is frontend-only: no backend, authentication or persistent saves. A separate fuller kit has been built with connected table/detail/pipeline views; it is not yet available for purchase.

If you're building a lead dashboard, try the table interactions and inspect the source before deciding whether it fits your application.
