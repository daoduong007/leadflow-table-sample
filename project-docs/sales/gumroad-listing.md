## Product description — paste after support/refund terms are finalized

### Build a connected lead dashboard in Next.js

LeadFlow gives developers a source starter for a lead dashboard: a searchable table, a lead detail screen and a five-stage pipeline that share the same client-side data.

Use it as the UI foundation for an internal tool or a client project. Adapt the TypeScript models and plain CSS, then connect your application's own backend.

### What you receive

- Next.js App Router, React and TypeScript source with an npm lockfile.
- Lead table with name/company search, status filtering, pagination, row/page selection and bulk status changes.
- Lead detail with owner/status controls, notes and mock activity history.
- Five-column Kanban pipeline with keyboard/touch-friendly status controls. Cards move using a select control; drag-and-drop is not included.
- Shared updates across table, detail, pipeline and summary metrics.
- Responsive layouts and ready/loading/error/empty demo states.
- Setup, customization and backend integration-boundary guides.
- A short, silent screencast of the actual kit.
- Unit and browser tests, source license and third-party notices.

Delivery is a versioned ZIP: `leadflow-ui-kit-v0.1.0.zip`.

### Requirements and scope

You need JavaScript/React development skills, Node.js 20.9+ and npm. The bundled versions are Next.js 16.4.0 and React 19.3.0; the release was checked with Node.js 20.20.2 and Chromium desktop/mobile emulation. Start with `npm ci`, then `npm run dev`.

This is a developer UI kit with 12 fictional records. It does not include backend, authentication, database, persistent saves, server-side pagination, CRM integrations, hosted accounts or installation services. Refresh resets edits. Loading/error states are demonstrations; no network request is made. Detail is a client view without its own URL. Table filters apply to the table; pipeline shows all records.

### FAQ

**Can I use it for client work?** Yes, within the included source license. Handing over a client end product is permitted; distributing the standalone paid kit for unrelated reuse is not.

**Is this a working hosted CRM?** It is source code for developers. You must implement your own backend, auth and deployment to operate a real application.

**Will changes survive reload?** No. Demo state lives in memory. The customization guide explains the boundaries to replace when integrating your data layer.

**Is Kanban drag-and-drop included?** No. Each card has a status selector that works with keyboard and touch.

**Do I need API keys?** No keys, accounts or environment variables are needed to run the included demo locally.
