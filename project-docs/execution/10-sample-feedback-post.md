## Tiếng Anh

**Free Next.js lead table sample — feedback from dashboard builders welcome**

I made a small free Next.js + TypeScript lead table for developers building CRM interfaces or internal tools. You can try name/company search, status filters, combined filters and the empty state. The table also scrolls on mobile.

The demo uses 12 fictional contacts. There is no backend, sign-in or persistence. It includes MIT-licensed source, mock data and a setup guide; no email or purchase is needed to download it.

Demo + source: https://leadflow-table-sample.daotungduong-photos2.chatgpt.site

GitHub source: https://github.com/daoduong007/leadflow-table-sample

The free source ZIP download is also under “What’s included” in the demo.

If you have worked on a similar dashboard recently, I would like to know:

1. Does this table fit a current project? What stack/template are you using?
2. Could you run the sample from the README? Where did you get stuck?
3. Does your project need a connected table/detail/pipeline, or is a table enough? What do you currently use instead?

A separate fuller kit has now been built with connected table/detail/pipeline views; it is not yet available for purchase. Demand and the proposed price remain unvalidated.
