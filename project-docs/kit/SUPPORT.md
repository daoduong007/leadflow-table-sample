# Support scope — release v0.1.0

The intended scope covers reproducible defects in the unmodified kit and unclear setup instructions using its included lockfile and supported Node version. A report should include kit version, Node/npm versions, operating system/browser, steps, expected result, actual result and a minimal reproduction. Remove secrets and real customer data before sharing logs or screenshots.

Custom features, backend/auth integrations, deployment work, design changes, third-party API configuration and debugging an extensively modified application are outside the kit's included support scope. No response-time or lifetime-update guarantee is offered in this release.

This build has not yet been listed for sale, so there is no customer support inbox or purchase-verification channel configured. Before selling, the seller must add a working support contact in the listing and delivery instructions, and state the refund/updates terms there. Do not direct paid-kit source or customer purchase details to the public free-sample GitHub issues.

The original free sample is separately documented in its public repository. This policy does not claim that anyone has bought this kit or that checkout/support automation is active.
